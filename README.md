# LIRAS
The LMIRCam Imaging Reduction and Analysis Suite -- a pipeline for data reduction and analysis of high-contrast imaging observations using LBT/LMIRCam

Routines are provided for both reduction of LMIRCam data in the "ReductionRoutines" folder and for analysis of the reduced data in tbe "AnalysisRoutines" folder. Full tutorials for the reduction and analysis pipelines are provided via Jupyter Notebook in the "Tutorials" folder.
Example science and calibration LMIRCam files for use in testing the pipeline are provided in the "files" folder.
